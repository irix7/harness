# Harness

This repository is reserved for the agent harness.

## Purpose

The harness will orchestrate the transcription of IRIX into a portable Rust-native system.

For each transcription step the harness will:

- start and record the agent sessions
- collect the evidence for the step
- verify the step against the evidence

The transcription is planned work. It follows the two deliverables in the project repository: the stock rebuild and the modernised fork. See https://github.com/irix7/project.
